# Home Cybersecurity Lab

## Overview

A personal cybersecurity laboratory designed to develop practical skills in network security, Linux administration, vulnerability assessment, ethical hacking and security monitoring.

The lab uses virtual machines to create an isolated environment for conducting authorized security experiments, studying vulnerabilities and implementing defensive security controls.

## Objectives

- Build and manage isolated virtual cybersecurity environments.
- Understand Linux server administration and network security.
- Perform authorized vulnerability assessments.
- Study web application security.
- Monitor system activities and security events.
- Document vulnerabilities, remediation and experimental results.

## Lab Architecture

The planned environment consists of:

| Component | Purpose |
|---|---|
| Kali Linux | Security testing workstation |
| Ubuntu Server | Server administration and defensive configuration |
| OWASP Juice Shop | Intentionally vulnerable web application for training |
| Wazuh | Security monitoring and event analysis |
| VirtualBox | Virtualization platform |

All vulnerable practice targets will operate within an isolated laboratory network.
